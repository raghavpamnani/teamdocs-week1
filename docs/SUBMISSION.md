# Submission checklist

- [ ] Public GitHub repository opens in a signed-out browser.
- [ ] README setup and run instructions are present.
- [ ] GitHub Actions test and container jobs are green.
- [ ] Rehearse the workflow using the sample file.
- [ ] Record a 2–3 minute Loom in your own voice.
- [ ] Verify the Loom sharing settings allow reviewers to watch it.
- [ ] Add the final Loom link near the top of the README.
- [ ] Submit the repository and requested details through the Google Form from the kickoff email.
- [ ] Reply to the bootcamp email thread with the Loom link.
- [ ] Watch other demos and react according to the bootcamp instructions.

The app uses sample accounts for local demonstration. Do not upload private documents into a publicly shared demo running those accounts.
